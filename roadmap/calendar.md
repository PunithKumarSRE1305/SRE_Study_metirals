# Calendar

Weeks in this repo are **journey weeks**, not calendar weeks.

```text
journey_start_date  +  (week_number - 1)  =  week start
```

Set `journey_start_date` in [`../progress/CURRENT.md`](../progress/CURRENT.md) on Day 1.

There are **134 journey weeks** in 31 × (365.25/12) / 7 ≈ 134.7.  
The weekly tracker lists **W01–W134**. Month 31 uses the last weeks for interview + portfolio polish and slack.

If you pause a month, **do not renumber weeks**. Add a `pause` note in the weekly tracker. The roadmap is a sequence, not a promise to a date on a wall.

## Holidays / crunch

Each month has a revision/assessment tail. That is the first place slack comes from. The last month is also slack.
