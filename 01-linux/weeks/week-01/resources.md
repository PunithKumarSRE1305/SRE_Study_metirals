# Week 01 — free resources

**This week in the repo:** what Linux is, kernel vs user space, terminal vs shell, FHS, paths, `pwd` / `ls` / `cd`.

Watch **after** or **beside** the day file, not instead of it. Cap: 20–30 minutes of video per evening.

## Official / open tutorials

| Concept | Resource | Why this one |
| ------- | -------- | ------------ |
| Whole week spine | [LFS101 — Introduction to Linux](https://training.linuxfoundation.org/training/introduction-to-linux/) (free) | Official Linux Foundation. Audit it slowly across Months 1–3. |
| Command line book | Shotts, *The Linux Command Line*, ch. 1–3 — [free PDF](https://linuxcommand.org/tlcl.php) | Navigation, `pwd`, `cd`, `ls`, paths. |
| Interactive lessons | [Linux Journey — Command Line](https://labex.io/linuxjourney) · [GitHub source](https://github.com/labex-labs/linuxjourney) | Short pages. Do "The Shell" + "pwd/cd/ls". |
| FHS spec | [Filesystem Hierarchy Standard 3.0](https://refspecs.linuxfoundation.org/FHS_3.0/fhs/index.html) | The actual standard. Skim, do not memorize. |
| Kernel / user space | [Kernel.org — user-space vs kernel](https://docs.kernel.org/) (context) + this week's visual | Official docs are dense; use our visual first. |
| Live practice | [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) levels 0–2 | Forces `ssh`, `ls`, `cd`, `cat`. Optional Sunday. |
| Browser box | [Killercoda](https://killercoda.com/) Linux scenarios | If you have no VM tonight. |
| Command help | `man pwd`, `man ls`, `help cd` · [explainshell ls -la](https://explainshell.com/explain?cmd=ls+-la) | Primary reference. |
