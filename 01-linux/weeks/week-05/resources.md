# Week 05 — free resources

**This week:** CPU, memory, /proc, load average

Videos are optional. Cap 20–30 minutes. The week file in this folder is the lesson.

## Concepts this week

| Load average | A queue length, not a CPU percent. |
| CPU vs iowait vs steal | Three different ‘busy’ stories. |
| RSS vs cache vs available | Cache is not ‘used up’ the way Windows Task Manager implied. |
| `/proc` as an API | The kernel answering questions dressed as files. |
| OOM | The kernel murdered a process to save the box. |
