# Week 08 — free resources

**This week:** SSH, sudo, Linux admin mini-project

Videos are optional. Cap 20–30 minutes. The week file in this folder is the lesson.

## Concepts this week

| Keys not passwords | A key pair is identity. Protect the private half. |
| `~/.ssh` permissions | ssh will refuse a world-readable key. That is a feature. |
| sudoers | Least privilege, not ‘everyone is root with extra steps’. |
| Lockout recovery | Break-glass console exists because SSH dies. |
| Mini-project | User + unit + logs on a lab box. |
