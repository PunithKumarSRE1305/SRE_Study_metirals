# Week 07 — free resources

**This week:** systemd, journals, cron, time

Videos are optional. Cap 20–30 minutes. The week file in this folder is the lesson.

## Concepts this week

| Units | A service is a file plus a process the manager watches. |
| enable vs start | Now vs every boot. |
| `journalctl` | The first place logs live on modern distros. |
| cron vs timers | Two schedulers. Know which one you actually have. |
| Time drift | TLS and logs lie when the clock is wrong. |
