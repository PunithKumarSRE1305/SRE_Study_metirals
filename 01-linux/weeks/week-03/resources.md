# Week 03 — free resources

**This week:** Users, groups, permissions

Videos are optional. Cap 20–30 minutes. The week file in this folder is the lesson.

## Concepts this week

| Users and groups | `uid`/`gid` are numbers. Names are a convenience in `/etc/passwd`. |
| Permission triads `rwx` | Three classes: user, group, other. |
| Octal `chmod` | 4+2+1. `750` is a decision, not a spell. |
| Directory `x` vs `r` | `cd` needs `x`. `ls` needs `r`. They are different. |
| `sudo` vs logging in as root | Least privilege. Root login is a last resort. |
