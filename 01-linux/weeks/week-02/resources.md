# Week 02 — free resources

**This week:** Files, text, finding things, editors

Videos are optional. Cap 20–30 minutes. The week file in this folder is the lesson.

## Concepts this week

| Files vs names vs inodes (revisit) | A name is a label on an inode. `rm` removes a name. |
| `touch` / `mkdir` / `cp` / `mv` / `rm` | Create, copy, move, remove — and what `rm` does not do to an open file. |
| `cat` / `less` / `head` / `tail` / `tail -f` | How an SRE actually reads logs. |
| Globs and `find` | The shell expands `*`. `find` walks the tree. |
| Editors enough to survive (`nano`, `vi` basics) | You must edit a file on a box with no IDE. |
