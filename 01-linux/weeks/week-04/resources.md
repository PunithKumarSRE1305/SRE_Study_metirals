# Week 04 — free resources

**This week:** Processes + Month 1 gate

Videos are optional. Cap 20–30 minutes. The week file in this folder is the lesson.

## Concepts this week

| What a process is | A running program: pid, ppid, uid, cwd, fds. |
| `ps` and `top` | Columns are kernel bookkeeping, not decoration. |
| Signals | SIGTERM is polite. SIGKILL is a kernel sledgehammer. |
| State `D` | Uninterruptible sleep. Usually disk. `-9` will not help. |
| pid 1 | If systemd dies, the box is not a box anymore. |
