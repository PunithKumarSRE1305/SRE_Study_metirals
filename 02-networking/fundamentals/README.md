# Networking fundamentals

Opens in **Week 11 / Month 3**, after Linux troubleshooting and bash essentials.

We will not start here in Month 1. If you are reading this out of curiosity on a Sunday, fine. It does not change `CURRENT.md`.

## When it opens you will learn

- Why networks exist for an SRE (not "so JMeter has a URL")
- OSI vs TCP/IP as maps, not religion
- Encapsulation: HTTP → TCP → IP → Ethernet
- The difference between "the site is down" and "which layer died"

## PT bridge (preview)

`Connection refused` vs `timeout` vs `UnknownHostException` in JMeter are already layered errors. This module gives those errors their proper names and the commands that prove them.
