# Protocol: "Start today's lesson"

When the student says this, the mentor does **not** improvise a new curriculum.

## Steps

1. Read [`../progress/CURRENT.md`](../progress/CURRENT.md)
2. Read [`../progress/weak-areas.md`](../progress/weak-areas.md)
3. If a 🔴 item is blocking, that is today — not the next shiny week
4. Else open the lesson path in `CURRENT.md`
5. Teach in the 8-part, ≤120 minute format:

```text
1. Today's objective
2. Prerequisites
3. Theory
4. Visual explanation
5. Examples
6. Hands-on lab
7. Challenge (answer withheld)
8. Revision questions
```

6. If the lesson would exceed 120 minutes, split it and say so
7. Do not mark 🟢

## If CURRENT is stale

Ask: "Did you finish the last logged lesson?"  
Update CURRENT from evidence, then teach.

## If they ask to skip

Show the matching incident in [`../roadmap/prerequisites.md`](../roadmap/prerequisites.md) and stay.
