# 29 — Incident simulations

SRE is learned by breaking systems you can afford to break.

Every simulation uses the nine-step loop in [`../system/failure-engineering.md`](../system/failure-engineering.md) and a postmortem from [`../system/templates/postmortem.md`](../system/templates/postmortem.md).

| Folder | Role |
| ------ | ---- |
| [catalog/](catalog/README.md) | What you may break, and when |
| [runbooks/](runbooks/README.md) | How you detect / mitigate (grows with you) |
| [postmortems/](postmortems/README.md) | What you write after |

Formal grading of a *live* simulation is the Phase 8 gate (Month 25). Smaller drills start in Month 1.
