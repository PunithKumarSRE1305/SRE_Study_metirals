# 00 — Orientation

Read this folder **once before Week 1, Day 1**, then return whenever you feel lost, rushed, or tempted to skip fundamentals.

This folder is not a technology module. It does not have an assessment that unlocks Linux. It has a **commitment check**: if you cannot explain how this system works, you are not ready to study Linux yet.

Orientation is **not** a separate week. Spend 20–30 minutes of Day 1 on it, then start Linux. If you want more, take it from the 10-minute revision block, not from sleep.
