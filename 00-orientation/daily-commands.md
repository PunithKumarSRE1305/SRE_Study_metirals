# Phrases that drive the mentor

| You say | What happens |
| ------- | ------------ |
| `Start today's lesson` | Mentor reads `progress/CURRENT.md`, then teaches ≤120 minutes |
| `I finished today's lesson` | You are told what to log. Nothing becomes 🟢 |
| `I am ready for assessment` | Unlock only if labs are logged and nothing blocking is 🔴 |
| `Grade my assessment` | Scores, updates trackers from evidence |
| `I am stuck` | Prerequisite check first |
| `Skip ahead` | Refused if a gate is missing |
| `I missed a day` | Plan adapts. Not a failure |
| `Weekly review` | Tracker update |
| `Monthly review` | Month N write-up |
| `I still don't get X` | X is added to weak areas. This is strength. |
