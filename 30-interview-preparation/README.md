## What an interview question is for, early

Each Week 1 concept doc already has beginner → advanced questions. Answer those **after** the lab, as retrieval practice — not as a flashcard deck to finish the week.

## Month 31 loop

1. Linux + networking live debug
2. AWS + Terraform + K8s
3. SRE scenario + error budget
4. Behavioral using **this repo's** postmortems
5. Portfolio walkthrough of 🟢 versions only

Passing bar: a mentor (or a peer) would say "hire" for a junior/mid SRE, not "knows the words."

## Your unfair interview advantage

You can talk about **load, saturation, percentiles, and soak** without blinking. The work is to attach those words to Linux, SLOs, and incidents you actually ran.
