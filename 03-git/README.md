## Why this module exists

Git is how every pipeline, GitOps idea, and incident 'what changed?' starts. If Git is a bag of memorized commands, you will panic on a bad rebase.

## Prerequisites

Comfort in a shell, files, editors.

If they are not 🟢, stop. See [`../roadmap/prerequisites.md`](../roadmap/prerequisites.md).

## Performance-testing bridge

Treat commits like test baselines: a known good you can return to. `git revert` is the rollback of source.

## You will be able to

- Explain working tree / index / commit
- Branch, merge, and resolve a conflict without losing work
- Use revert in preference to rewrite on a shared branch
- Write a commit message an on-call can use at 02:00
